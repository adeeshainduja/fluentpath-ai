## Phase 5: After Login

Instead of hardcoding:

```text
Learner ID = 1
```

you should use the authenticated user's ID from the JWT.

For example, replace:

```ts
const learnerId = 1;
```

with something like:

```ts
const { user } = useAuth();

const learnerId = user.id;
```

This will make your Dashboard, Profile, Analytics, Learning Path, and AI Coach automatically show data for the logged-in learner.

4. ✅ Current user endpoint (`/auth/me`)
5. ✅ Replace all hardcoded `learnerId = 1` with the authenticated user's ID

That gives you a complete authentication system that's much easier to maintain.

1. **Backend**

   * Register endpoint
   * Login endpoint

2. **Frontend**

   * Login page

3. **Integration**

Once that's done, the rest of the project will naturally become multi-user and your existing intelligence layer will work for whichever learner is signed in. This is a solid foundation for the final stage of FluentPath AI.
